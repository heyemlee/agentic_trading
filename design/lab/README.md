# 研究室 · 独立设计预览

## 当前版本：单角色连续动作试作

第四版默认只播放风控圆桌后方中性分析师的分层微动作，其他角色不再切换整张姿态图，也不自动发起旧版走路。旧版走路按钮保留供手动对比。点击「放大查看连续动作」可查看同一角色的近景。

- `rig.js`：在同一坐标空间装配头部、躯干和两条完整手臂。
- `rig.css`：使用 6.8、7.7、8.9、9.6 和 12.4 秒五种不同周期，连续插值呼吸、身体重心、头部和双手的小幅动作，避免同步和机械重复。暂停/继续保留当前动画时间。
- `assets/neutral-parts-v4.png`：内置图像生成制作的部件图集，SVG 遮罩限定部件轮廓并排除生成图的背景光晕；不是纯矢量绘制的人物。
- 房间、桌椅和其他人物保持原有比例及位置，原中性分析师以空席局部图覆盖，再装配独立人物。工位中角色未启用时隐藏，停住/中断/减少动态效果时停止动作。

抬杯饮水动作已从当前版本移除。本轮用于评估低幅度连续动作，尚未制作精细手指、表情口型、起身坐下衔接或全员分层动画。下方第三版内容是之前方案的记录，不是当前默认播放方式。

第四版素材提示词：以原圆桌中性分析师为身份和画风参考，生成三列两行部件图集，分别为头部、躯干、左右手臂、白色杯子和闭眼头部，锁定比例和光照；追加去除背景与光晕编辑。全部使用内置 image_gen；最终选用图集保存为上面的本地 PNG。此次只使用一个头部，头部和手臂的动作依靠变换插值，不交叉淡化整个人物姿态。

入口：[index.html](index.html)。直接用浏览器打开，或只将此目录作为静态目录提供访问。没有构建步骤、外部图片请求、字体服务、后端连接、凭据、离线缓存和审批持久化。

本目录独立于 `ui/`，没有修改生产配置、账本或正在运行的 API。全站始终标注设计预览及示例数据。`running` 也只是固定的运行中样例，不是实时连接。

## 已确认的设计

- 固定斜俯视 2.5D 办公室，浅橡木、灰绿家具、暖色日光。
- 分析桌、辩论桌、交易与评级台、风控圆桌，共 12 个角色。
- 不设休息区、独立经理室、实体闸机、玻璃隔断或前台。
- 投资组合经理保留为评级角色。风控裁决和真人审批以普通界面呈现。
- 人物可离座移动，报告交接仍以文件传递表示。

## 文件

- `index.html`、`lab.css`、`lab.js`：独立预览页面。
- `assets.html`、`assets.js`：角色源文件浏览、下载与灰显检视。
- `assets/office-reference.png`：用户已确认的美术方向。
- `assets/office-seated-v2.png`：按实际椅子、桌面和屏幕透视绘制的十二人入座场景。
- `assets/office-empty-v2.png`：对应的空办公室，用局部遮罩显示未启用或离座工位。
- `assets/role-portfolio-walk-v2.png`：投资组合经理的八格走路图集，四列两行；背面、正面各四格。
- `assets/office-gesture-v3.png`、`assets/office-sip-v3.png`：转头、打字/鼠标手势、交谈张嘴和喝水的场景关键帧，按角色局部显示。
- `assets/role-*.png`（不含 walk）：第一版独立两帧素材，保留在素材页供参考，不再用于场景坐姿。
- `assets/empty-chair.png`：单独空椅子素材。办公室中未启用工位直接显示背景里的原椅子。
- `verify.cjs`：离线交互逻辑与本地资源检查。

所有栅格美术通过内置图像生成制作。没有复制 PixelHQ 或 AI Office React 的角色、贴图或素材。最终素材是 PNG，不是可编辑 SVG。第二版的坐姿与家具一起绘制，解决各工位朝向和遮挡；点击热区、状态标签、空席遮罩和走路角色仍是独立界面层。坐姿不是十二张可自由移动的透明素材。素材页保留第一版两帧素材，明确标为旧版。

## 状态与数据

`lab.js` 中的 `roles`、`sequence` 是示例数据。接入真实系统时需要替换为真实事件，并由后端提供角色启用掩码、时间戳、额度、下次运行时间和规则结果。当前仅示例公司财报角色在 ETF / 加密下未启用，不应将其作为生产启用规则。

七种状态：不启用、待命、思考中、查资料、交出、停住、中断。页面底部「设计检视」可逐一查看。停住不推断为失败；也不推断角色动画具有实际工作进度含义。所有持续时间都是对应示例事件的数据，没有百分比、旋转加载或模拟增长计时器。

回放模式按事件前进和后退。休息模式展示上次角色摘要、剩余额度与明确时区的下次运行时间。示例最后的 `NO_TRADE` 与 `hard_risk: PASS` 分别表示策略不交易与硬风控通过，不等价于可交易。

审批按钮在本预览中始终禁用；没有发单、批准或执行操作。

## 动态与主题

第三版默认自动播放办公室氛围动作，不再需要点击才动。角色按不同相位切换局部动作关键帧；喝水从市场、Bear、中性三个角色中随机选择，首次约 4 秒，随后约 21–35 秒出现一次。轻动作包括眨眼/转头、键盘/鼠标手势切换、张嘴与讨论手势。它们是少量关键帧组成的动画预览，不是精细的逐指或骨骼动画。

约 8 秒后自动发起一次投资组合经理的往返交流，此后间隔约 42–59 秒；点击「演示往返走路」也可立即触发。离座时工位显示空椅子，独立人物沿中央过道走到辩论桌旁，停留并显示交流气泡，再转向走回。正面/背面各四格步态循环，人物尺寸从场景宽度的 20% 调到 26%，与入座人物头部比例相近。离座与入座仍为姿态切换，尚无连续起身、坐下或转身过渡帧，也不是自由寻路。其他十一位角色尚未制作走路图集。

「思考中 / 查资料」显示循环省略号气泡；不是进度条。氛围动作不改研究事件、角色状态、额度、规则裁决或活动流。未启用、停住、中断的角色不播放氛围动作；离座期间不显示重复坐姿。可通过「暂停办公室动态」一键停止。页面隐藏或系统开启 `prefers-reduced-motion` 时取消所有动画与定时器；页面重新可见后按设置恢复。减少动态效果时气泡保留静态文字与点，人物位置不变。

流畅度修订：动作图层只创建一次，以工位大小的局部背景显示；状态变化时过渡透明度，不再每 700 毫秒销毁重建整张场景图片。重复动作增加保持时间，气泡内容不变时不重建，走路改用 transform 平移。素材仍为有限姿态帧，过渡优化不等于新增连续动作帧。所有场景气泡统一使用 `--lab-bubble-bg/text/line` 的白底深字样式。

深浅主题的界面颜色定义于 `lab.css` 的 `--lab-*` 变量。当前深色房间使用相同背景的亮度与饱和度适配；并非独立夜间重绘。角色服装颜色保留识别一致性。

手机端办公室与详情纵向排列；桌面将同一办公室置于左侧、工位和事件置于右侧。角色名在场景内按选中/活动显示，完整名称与状态始终在工位列表中可读。

## 素材提示词摘要

背景：以已确认办公室为唯一编辑目标，保留四个工作区、家具、空椅子、日光和透视，移除所有人物；不增加休息区、经理室、闸机和前台。

第二版入座：保持参考办公室的画幅、家具和十一位坐姿人物，将过道中的白衬衫马尾女性移到左下方右侧工位；背向观察者、面向电脑，手臂伸向键盘，白色椅背正确遮挡身体。第二版空席：从该入座场景移除十二人，保留家具位置及画幅。第二版走路：同一女性的透明四列两行图集，上排背面朝远处走，下排正面朝近处走，左右脚交替和经过姿势，保持比例、服装、光照和格子对齐。

第三版动作（内置 image_gen 编辑）：以第二版入座为唯一编辑目标，锁定 1024×1536 画幅、家具、座位、人物身份、比例和光照，只改变头部与手部；电脑角色轻微转头、眨眼和切换键盘/鼠标手势，围桌角色略张嘴并改变讨论手势。第三版喝水（内置 image_gen 编辑）：相同场景，仅市场分析师、Bear 研究员和中性分析师举白色杯子喝水，其余角色保持不变。最终文件为上方列出的两个 v3 PNG，均保存在本目录 assets 中。

角色：参考同一办公室的卡通比例与光照；每张为透明背景、左右等宽两格、同一人物左坐右站，不包含家具与文字。以发型、服色、平板/报纸/报表等道具区分 market/news/social/fundamentals/bull/bear/manager/trader/aggressive/neutral/conservative/portfolio。

空椅子：与办公室灰绿椅子一致，透明背景、固定斜俯视、无人物、无文字。

## 交付边界

这是插画素材组成的独立交互预览，尚未接入控制台数据。进一步制作独立的逐角色多朝向坐姿素材、全员走路图集、起身坐下过渡、物理寻路、任意视角或家具级拆分属于后续细化。当前坐姿场景优先保证实际工位的透视和遮挡。
